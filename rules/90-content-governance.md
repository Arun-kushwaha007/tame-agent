# Rule 90: Content Governance & SEO Integrity

## Purpose

Enforces rules for content creation, SEO structure, and verification workflows to maintain search engine authority and user trust.

## When It Applies

Applies to all marketing pages, blog posts, educational content, dynamic routes, and SEO metadata.

## Non-Negotiable Rules

1. **SEO as Product Architecture**:
   - Do not treat SEO as metadata added at the end.
   - Every indexable page must provide distinct, real value to users.

2. **Zero Thin Content**:
   - Never create mass pages with only keyword changes (doorway pages).
   - Ensure dynamic routes offer substantial, unique content.

3. **Zero Fake Claims**:
   - Never invent statistics, fake reviews, dummy compliance badges, or unverified claims.
   - All data presented to the user must be accurate and verifiable.

4. **Content Verification Workflow**:
   - Implement a multi-gate verification workflow for complex informational content.
   - Example Workflow: `Research -> Draft -> Fact-Check -> SEO & Schema Check -> Editorial Review -> Publish`.
   - Verify formulas, legal rules, and regulatory information against official sources before publishing.

5. **Content Lifecycle Status Model**:
   - Maintain a clear status model for CMS entries (e.g., Draft, Review, Approved, Published, Archived) to prevent accidental release of unverified content.
