## [1.1.0] - 2026-11-17

### 🚀 Highlights
- **24 Production-Grade Modular Skills**: Complete skill packages with `SKILL.md`, `metadata.yaml`, `reference.md`, and copy-paste `examples/` covering Next.js 15/16 App Router, React 19, Tailwind CSS v4, Technical SEO, TanStack Query v5, Vitest, Playwright, and more.
- **Technical SEO Development & Deployment SOP (Rule 25)**: Comprehensive search architecture rules covering canonical URL defense, status code discipline (301/308 vs 302, zero soft-404s), dynamic XML sitemaps, robots.txt, and strict schema governance.
- **Autonomous SEO Specialist Agent Persona**: Pre-configured agent profile (`templates/agents/seo-specialist.md`) designed to perform automated pre-PR and pre-deployment SEO audits from the SEO Point of View (SEO POV).
- **ESLint Canonical Domain Defense**: Added `canonical-domain` rule to `eslint-plugin/index.mjs` with an automated code fixer (`fixable: "code"`) to catch and fix naked or non-canonical domain strings.
- **Zero-Duplicate Package Architecture**: Purged 197 duplicate files from repository source, keeping the npm package ultralight and clean.

### ➕ Added
- **Skills (`skills/`)**:
  - `web-technical-seo`: Complete technical SEO engineering pattern with 6 in-depth examples (`canonical-defense.md`, `metadata-factory.md`, `sitemaps-and-robots.md`, `schema-governance.md`, `status-codes-and-redirects.md`, `seo-testing.md`).
  - `tame-agent-governance`: Meta-skill for enforcing project engineering rules and verification workflows.
  - 22 modular web development skills: `web-meta-framework-nextjs`, `web-framework-react`, `web-styling-tailwind`, `web-styling-cva`, `web-ui-shadcn-ui`, `web-animation-framer-motion`, `web-forms-react-hook-form`, `web-forms-zod-validation`, `web-server-state-react-query`, `web-state-zustand`, `web-accessibility-web-accessibility`, `web-performance-web-performance`, `api-performance-api-performance`, `web-files-image-handling`, `web-testing-vitest`, `web-testing-react-testing-library`, `web-testing-playwright-e2e`, `shared-security-auth-security`, `shared-tooling-eslint-prettier`, `shared-tooling-git-hooks`, `infra-ci-cd-github-actions`, and `meta-reviewing-reviewing`.
- **Specialist Agent Personas (`templates/agents/`)**:
  - `seo-specialist.md`: Autonomous SEO POV Auditor enforcing the 10-point Technical SEO checklist.
  - `code-reviewer.md`: Architecture boundary, hook modularity, and file ceiling (< 500 lines) auditor.
  - `accessibility-auditor.md`: WCAG 2.1 AA compliance, keyboard navigation, and touch target auditor.
- **Engineering Rules (`rules/`)**:
  - `rules/25-technical-seo.md`: Technical SEO Development & Deployment SOP.
  - `rules/15-token-optimization.md`: Token Optimization & Terse Output Protocol ("caveman" mode, context preservation, minimal diff edits).
- **ESLint Plugin (`eslint-plugin/`)**:
  - `tame-agent/canonical-domain`: Rule enforcing canonical domain URLs with automated fixer (`fixable: "code"`).
- **CLI (`cli/index.mjs`)**:
  - Added `add-agents` command to copy specialist personas into `.agents/agents/`.
  - Updated `init` to recursively copy skills, rules, templates, specialist agents, and ESLint plugins.

### 🔄 Changed
- `templates/AGENTS.md`: Integrated SEO POV & Search Architecture Gate, Strict Schema.org Governance (zero unprompted/speculative schemas), Dual-Engine Architecture (SSR/SSG for SEO vs BFF for private apps), and 7-step lifecycle with SEO & a11y Gate.
- `eslint-plugin/package.json`: Renamed to `eslint-plugin-tame-agent` and bumped version to `1.1.0`.
- `README.md`: Overhauled documentation with full skill directory table, package vs project architecture diagram, and zero-impact guarantee.
- `templates/eslint-config-snippet.mjs`: Updated flat config snippet to include `canonical-domain`.
- `package.json`: Bumped version to `1.1.0` and added `CHANGELOG.md` and `templates/agents/` to published files.

### 🗑️ Removed
- Removed `.agents/` and `eslint-rules/` from source tree (these are generated by the CLI inside consumer projects).
- Removed stale `skills/SKILL.md` (superseded by `skills/tame-agent-governance/SKILL.md`).
- Cleaned up unneeded `.gitkeep` files across directories now populated with real content.
